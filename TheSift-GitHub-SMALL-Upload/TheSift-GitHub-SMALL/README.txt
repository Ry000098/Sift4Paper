THE SIFT - SMALL GITHUB BUILDER

Upload these THREE items to the ROOT of a new GitHub repository:
1. SiftProject.zip
2. the .github folder (contains workflows/build-sift.yml)
3. README.txt (optional)

IMPORTANT: Keep SiftProject.zip zipped. Do not extract it on GitHub.

Then:
1. Open the repository's Actions tab.
2. Choose "Build The Sift".
3. Click "Run workflow".
4. When it finishes, open the run and download the artifact named TheSift-Paper-26.3.
5. Extract the artifact and upload UPLOAD-THIS-TO-PEBBLEHOST.jar to your server's plugins folder.

If the Action turns red, copy the error from the Build plugin step and send it to ChatGPT.
